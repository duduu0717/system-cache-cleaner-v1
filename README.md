# 系统缓存清理工具 V1.0

一个面向 Windows 10/11 的轻量级桌面缓存清理工具。项目使用 Python 和 Tkinter 开发，核心流程为：

`扫描缓存 -> 选择项目 -> 确认清理 -> 查看结果`

## V1.0 范围

- 显示系统盘容量、已用空间和可用空间
- 扫描用户临时文件、Windows 临时文件和缩略图缓存
- 按类别显示文件数量和占用空间
- 用户选择清理项目，删除前二次确认
- 跳过无权限、被占用或不安全的目标
- 显示成功数量、失败数量、释放空间和耗时
- 生成本地操作日志

## 安全原则

- 仅访问程序内置的缓存目录
- 不扫描桌面、文档、下载、图片等个人目录
- 不提供任意目录删除功能
- 删除前再次校验文件必须位于允许目录内
- 不跟随符号链接，不递归删除整个目录
- 权限不足或文件被占用时记录并跳过

## 开发计划

1. 建立项目骨架和安全边界
2. 实现缓存扫描
3. 实现安全清理与日志
4. 实现桌面界面和完整操作流程
5. 增加自动化测试
6. 打包 EXE、完善操作说明书并发布

## 运行环境

- Windows 10/11
- Python 3.10 或更高版本
- Tkinter（Python Windows 安装包默认包含）

## 从源码运行

```powershell
python run_app.py
```

运行测试：

```powershell
python -m pytest -q
```

## 项目结构

```text
src/cache_cleaner/   核心扫描、清理逻辑和桌面界面
tests/               自动化测试
screenshots/         实际程序界面截图
docs/                Word 操作说明书
tools/               截图和文档生成工具
run_app.py           源码启动入口
```
