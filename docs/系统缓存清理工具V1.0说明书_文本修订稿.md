# 系统缓存清理工具 V1.0 操作说明

## 1 软件说明

系统缓存清理工具 V1.0 是一款 Windows 桌面程序，用于查看和清理本机常见缓存。程序目前检查用户临时文件、Windows 临时文件和缩略图缓存。扫描时只统计文件数量和占用空间，不会删除文件。用户选定项目并确认后，程序才开始清理。

本版本没有账号、联网和文件上传功能，也不需要安装数据库服务。软件不会扫描桌面、文档、下载、图片等个人目录。

## 2 运行环境

软件适用于 64 位 Windows 10 和 Windows 11。发布包内的 EXE 已包含运行所需组件，电脑没有安装 Python 也可以启动。

普通用户权限可以处理当前用户的临时文件。Windows 临时目录中的部分文件需要管理员权限。如果扫描结果中“Windows 临时文件”为 0，或者清理时出现较多失败项，可以退出软件，右键单击 EXE，选择“以管理员身份运行”。

## 3 获取和启动软件

收到 `系统缓存清理工具V1.0_测试题.zip` 后，先将压缩包完整解压到本地文件夹。不要直接在压缩软件的预览窗口中运行 EXE。

打开解压后的文件夹，双击 `系统缓存清理工具V1.0.exe`。程序启动后，窗口标题应显示“系统缓存清理工具 V1.0”。标题不一致时，应关闭程序并重新核对文件来源。

个人开发的软件没有商业代码签名。Windows 或安全软件可能在首次启动时显示提示。确认文件来自本项目 GitHub Release 后再继续运行。

## 4 首页

首页上方显示软件名称、版本号和当前权限模式。中间区域显示系统盘总容量、已使用空间和可用空间。程序读取的是启动时的磁盘状态，其他软件继续写入文件时，数值可能发生变化。

“开始扫描”按钮位于页面中部。按钮下方写有“扫描阶段不会删除任何文件”，用于区分扫描和清理两个步骤。窗口底部标明软件只处理预设缓存目录。

检查首页时，应先确认三个容量数值已经正常显示。如果数值显示为“无法读取”，不要继续清理，可关闭软件后重新启动。

## 5 扫描缓存

点击“开始扫描”后，页面切换到扫描状态。程序依次检查以下位置：

1. 当前用户的临时目录，即 Windows 环境变量 `%TEMP%` 指向的位置。
2. Windows 安装目录下的 `Temp` 文件夹。
3. 当前用户资源管理器目录中的 `thumbcache_*.db` 文件。

扫描页面会显示当前检查的类别、已经找到的文件数量和占用空间。文件较多时需要等待一段时间。扫描期间不要重复启动软件，也不要强制结束进程。

扫描不会修改原文件。遇到无权访问的目录或正在变化的文件时，程序跳过该项，继续检查其他文件。

## 6 查看扫描结果

扫描完成后，程序进入“扫描结果”页面。每一行对应一种缓存，左侧是复选框和用途说明，右侧分别显示文件数量和占用空间。

三个类别默认选中。需要保留某类缓存时，单击该行左侧的复选框取消选择。取消选择不会改变扫描结果，也不会删除该类别中的文件。

页面上方的可清理空间是三个类别的合计值。取消某个类别后，确认窗口会按实际选中的项目重新计算预计空间。

如果三个复选框全部取消，再点击“清理选中项目”，程序会提示至少选择一个项目，不会执行删除。

## 7 确认清理

选好项目后，点击“清理选中项目”。程序会弹出确认窗口，列出本次选择的缓存类别和预计释放空间。

先检查类别是否正确，再决定是否继续。点击“否”会关闭确认窗口并返回扫描结果，现有文件保持不变。点击“是”后开始删除，已经成功删除的文件不会进入回收站。

第一次使用时，建议只选择“用户临时文件”。确认这类文件能够正常处理后，再根据需要清理其他类别。

## 8 执行清理

清理页面显示当前处理的类别、已处理数量和已释放空间。程序按扫描结果逐个处理文件，每次删除前还会检查文件是否仍在对应的缓存目录中。

出现下面几种情况时，程序不会删除该文件：

- 文件已被系统或其他程序占用；
- 当前账号没有删除权限；
- 文件在扫描后已被移动或删除；
- 路径离开了程序允许的缓存目录；
- 目标是文件夹或符号链接。

单个文件失败不会中断整次任务。程序把失败数量记入结果，并继续处理后面的文件。清理期间应保持软件运行，避免在进度尚未完成时关机或注销。

## 9 查看清理结果

处理结束后，页面显示实际释放空间、成功文件数、失败文件数和清理耗时。预计空间与实际释放空间可能不同。例如，扫描完成后某个应用自行删除了临时文件，程序再次处理时就会将该文件记为失败或失效。

失败数量为 0 时，本次选中的可访问文件已经处理完毕。出现失败项时，可先关闭浏览器、资源管理器窗口或其他正在运行的软件，再返回首页重新扫描。Windows 临时文件持续失败时，可以使用管理员权限重新运行。

点击“返回首页”可以开始下一次扫描。重新扫描后显示的结果应以当前磁盘内容为准。

## 10 清理日志

每次执行清理都会生成一个文本日志，默认保存在：

`%LOCALAPPDATA%\SystemCacheCleaner\logs`

日志文件名包含清理时间，例如 `clean-20260908-153000.log`。文件使用 UTF-8 编码，可以用记事本打开。

日志按类别记录文件的处理结果。成功项包含文件大小和路径，失败项包含错误原因。日志末尾汇总成功文件数、失败文件数、释放字节数和耗时。

临时目录的路径中可能含有当前 Windows 用户名。需要把日志发给其他人时，应先打开检查，删去不希望公开的本机路径。

## 11 常见情况处理

### 11.1 Windows 临时文件显示为 0

普通用户可能没有权限读取 `C:\Windows\Temp`。先确认用户临时文件和缩略图缓存是否能正常显示。如果其他类别正常，可退出程序后使用管理员权限重新扫描。

### 11.2 清理失败数量较多

临时文件可能正被浏览器、安装程序或系统服务使用。关闭不需要的应用后重新扫描。仍然失败的文件可以保留，Windows 后续可能自行清理。

### 11.3 扫描结果与磁盘可用空间变化不一致

完成页面统计的是程序成功删除文件时读取到的大小。Windows 可能同时创建新的缓存，文件系统也可能延迟刷新容量显示。返回首页或重新打开资源管理器后再查看磁盘空间。

### 11.4 软件启动后没有窗口

单文件 EXE 首次启动时会先释放运行组件，通常需要几秒。等待后仍无窗口，可查看任务管理器中是否存在同名进程。结束重复进程，再从已解压的文件夹启动一次。

### 11.5 安全软件报出未知程序

本软件没有商业数字签名，个人项目打包的 EXE 可能触发信誉提示。可以先核对 GitHub 项目地址和 Release 文件，再在测试电脑或 Windows 沙盒中运行。不要关闭系统安全功能来启动软件。

## 12 清理范围

V1.0 只能处理程序内置的三个缓存位置。界面没有自定义目录输入框，用户不能把磁盘根目录或个人文件夹加入清理列表。

程序不会主动处理以下内容：

- 桌面、文档、下载、图片、音乐和视频；
- 浏览器收藏夹、密码、历史记录和 Cookie；
- 回收站；
- 软件安装目录和用户自行保存的文件；
- Windows 系统核心文件。

缩略图缓存被删除后，Windows 会在用户再次浏览图片或视频文件夹时重新生成缩略图。这不会删除原始图片或视频。

## 13 退出和卸载

没有执行扫描或清理时，可以单击窗口右上角的关闭按钮退出。清理过程中不建议直接关闭窗口，应等待完成页面出现后再退出。

软件采用免安装方式，没有写入开机启动项。卸载时关闭程序，删除 EXE 和解压后的项目文件夹即可。清理日志位于用户本地应用数据目录，不会随 EXE 一起删除。如不再需要，可在确认内容后手动删除日志文件夹。

## 14 使用问答

问：扫描会不会删除文件？

答：不会。扫描只读取文件路径和大小。点击“清理选中项目”并在确认窗口选择“是”后，程序才执行删除。

问：为什么缩略图缓存清理失败？

答：资源管理器可能正在使用缩略图数据库。关闭正在浏览图片或视频的资源管理器窗口，再重新扫描。

问：可以每天运行吗？

答：可以，但没有必要频繁清理。磁盘空间不足，或者临时目录积累较多文件时再使用即可。

问：电脑没有安装 Python，能不能运行？

答：能。发布版 EXE 已经包含 Python 和 Tkinter 的运行组件。

问：软件是否会联网？

答：不会。V1.0 没有网络请求、登录或上传功能。
