系统缓存清理工具 V1.0
========================

一、运行方法
1. 将整个压缩包解压到本地文件夹。
2. 双击“系统缓存清理工具V1.0.exe”。
3. 如需扫描 Windows 系统临时目录，可右键程序并选择“以管理员身份运行”。

二、核心功能
- 显示系统盘总容量、已用空间和可用空间。
- 扫描用户临时文件、Windows 临时文件和缩略图缓存。
- 分类显示文件数量和占用空间。
- 用户选择项目并确认后执行清理。
- 统计成功数量、失败数量、释放空间和耗时。
- 生成本地清理日志。

三、安全说明
- 软件只访问内置的三类缓存目录。
- 不扫描桌面、文档、下载、图片等个人目录。
- 删除前必须经过用户确认。
- 被占用、无权限或路径校验失败的文件会被跳过。

四、日志位置
当前用户目录下：AppData\Local\SystemCacheCleaner\logs

五、补充说明
本项目为 Python + Tkinter 开发的 Windows 桌面软件，EXE 已包含 Python 运行组件。
个人项目未配置商业代码签名，部分安全软件可能对首次运行进行提示。

项目地址：https://github.com/duduu0717/system-cache-cleaner-v1
